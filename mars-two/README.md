# mars-two

A working reconstruction of the kind of platform Aries Global describes as AriesOne:
one system that ingests the operating data of eight acquired B2B SaaS companies and
runs autonomous agents on top of it to execute sales, onboarding, customer success and
reporting workflows.

It is a learning build. Every module maps to a named skill in Andrew Ng's AI
Engineering Skills Map (August 2026), and `docs/skills-map.md` records the mapping so
the connection stays legible rather than implied.

## All data here is synthetic

The eight portfolio companies are fictional. Their names, financials, customers,
contracts, tickets and documents are generated by `platform/lib/synthetic/`. They
mirror the *shape* of Aries Global's real portfolio (European, founder-led,
Microsoft-ecosystem B2B SaaS) so the engineering problems are realistic, and they
mirror none of its actual numbers. Resemblance to any real company is coincidental.

## The portfolio

Eight companies, EUR 70.0M combined ARR.

| Company | Country | Sells | ARR | Revenue model |
| --- | --- | --- | ---: | --- |
| Vaultline | France | Active Directory access security | EUR 12.0M | Perpetual licence migrating to subscription |
| Meterpath | Latvia | Cloud marketplace billing and CPQ | EUR 14.5M | Usage plus subscription, multi-tier channel |
| Northquay | Italy | Strategic portfolio management | EUR 8.2M | Per-seat enterprise |
| Deskwright | Netherlands | Digital workplace | EUR 11.0M | Per-seat through MSP channel |
| Sayline | Spain | Conversational customer engagement | EUR 6.4M | Usage, priced per conversation |
| Tidyrecord | United Kingdom | Customer data quality for Dynamics 365 | EUR 5.1M | Per-record plus subscription |
| Roomcast | Denmark | Workspace booking and signage | EUR 7.3M | Per-room plus per-seat |
| Clausemark | Germany | Contract lifecycle management | EUR 5.5M | Per-seat |

The mix is deliberate. Eight companies that all counted ARR the same way would make
cross-portfolio comparison trivial and would teach nothing. These eight disagree about
what counts as recurring, which is the actual problem a group operator has.

## Architecture

Three services, chosen to match the stack Aries publishes in its own job specs:
Ruby and Python on the backend, React on the front.

```
                         +---------------------+
                         |  web  (React + TS)  |
                         +----------+----------+
                                    | JSON over HTTP
                                    v
   +---------------------+   +------+--------------+
   |  intelligence       |<--+  platform (Rails 8) |
   |  (Python, FastAPI)  |   |  API only           |
   |                     +-->|                     |
   |  tool registry      |   |  tenancy + RLS      |
   |  agent runtime      |   |  metric rollups     |
   |  retrieval          |   |  integrations       |
   |  eval harness       |   +----------+----------+
   +----------+----------+              |
              |                         |
              +------------+------------+
                           v
                  +--------+---------+
                  |  Postgres 16     |
                  |  + pgvector      |
                  +------------------+
```

`platform` owns the data, the tenant boundary, and every number. `intelligence` owns
retrieval, the agents, and the evals. Models never compute: every figure an agent
states was calculated in SQL by `platform` before the agent saw it, and the agent's
job is to select, explain and act on it.

## Quickstart

```bash
make setup     # install deps, create databases, run migrations, seed synthetic data
make test      # rspec, pytest, tsc, lint
make evals     # run the eval suite against recorded fixtures
make dev       # run all three services
```

No `ANTHROPIC_API_KEY` is required. The default Anthropic client replays recorded
fixtures, so the whole suite runs offline and deterministically. Export a real key and
set `MARS_LLM_MODE=live` to make real calls.

## Repo layout

| Path | What lives there |
| --- | --- |
| `platform/` | Rails 8 API. Schema, tenancy, role scoping, metric rollups, synthetic data generator |
| `intelligence/` | Python FastAPI service. Tool registry, agent runtime, retrieval, eval harness |
| `web/` | React and TypeScript front end |
| `docs/adr/` | Architecture decision records, one per decision that had a real alternative |
| `docs/design/` | The UI design brief, written and signed off before any front-end code |
| `docs/log/` | Build log: what context the coding agent was given, what it got wrong, what fixed it |
| `docs/skills-map.md` | Which module exercises which skill from the Skills Map |
