# memory

Plain markdown, committed, read first by any session picking this up.

Three files, and the split matters. `decisions.md` is what was settled and is not
reopened. `preferences.md` is how the work is done. `state.md` is where the build
is, and it is the only one that changes often.

Anything that would have to be re-derived from a transcript belongs here. A
decision that lives only in a conversation is a decision that gets made twice.
