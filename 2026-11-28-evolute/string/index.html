involute · noun · the curve traced by the end of a taut string unwound from another curve — the reverse of the evolute, which that other curve then is

String

A tight thread peeled off a curve, and the new curve its free end writes.

Pin a thread along a curve and peel it off, keeping it tight. The free end draws a new curve — the involute — and the thread is always a straight tangent to the base at the point it last left, exactly as long as the arc it has let go of. That one fact closes the circle with the page before: because every taut thread is tangent to the base, the base is the envelope of the involute's normals — which is to say the base is the evolute of the involute just drawn. Unwinding and taking the evolute are one move run backwards. Let a string off a circle and you get the spiral that shapes every gear tooth; off a cycloid, an equal cycloid, the curve Huygens hung a pendulum along to keep true time; off an astroid, a larger astroid. Nothing is drawn from a formula — the string is let out by real arc length, and the curve follows its end.

The bench

One base curve, and the string let off it

The gold curve is the base, held still. A steel thread is pinned at one end and peeled away, drawn tight; the copper curve is the path of its free end. At any moment the thread runs straight from the point it last left the base — tangent there — out to its tip, and its length is exactly the arc it has released. Draw the thread at many stages at once and you see the trick of it: every thread touches the base, so the base is the curve all those threads wrap — the envelope of the new curve's normals, its evolute. Let the string all the way out and the involute is complete; the base is the evolute it came from.

Why the string draws the evolute's own curve back

Unwinding is the evolute run backwards

  • Hold the thread tight and let a little more off. The piece just released was wrapped against the base; now it swings out straight, tangent to the base at the point it leaves, and its length has grown by exactly that released arc. The free end moves square to the thread — so the thread is the normal of the curve the end is drawing.
  • That makes the base the envelope of the involute's normals: every taut thread is one of the involute's normals, and every thread touches the base. By the definition on the other page, the envelope of a curve's normals is its evolute — so the base you unwound from is the evolute of the involute you drew. Unwinding is the evolute, taken backwards.
  • So the two operations undo each other. Take a curve's evolute and you fold its curvature away into a companion curve; unwind a string from that companion and you get the original back (up to how far off the pin you started — a curve has one evolute but a whole family of involutes, one for each length of string). Forward on the centres page, backward here.
  • Which involute you get depends only on the base. A circle pays out the involute of a circle, an Archimedean-looking spiral whose coils stay a constant thread's-width apart — the exact flank a gear tooth needs so that meshing teeth roll without sliding. A cycloid pays out an equal cycloid, shifted by half an arch: the fact Huygens used to swing a pendulum between two cycloidal cheeks so its period would not drift with amplitude. An astroid pays out an astroid twice as large.
  • Every one of these is read off the string, not plotted. The page lays down the base, measures real arc length along it, and sets the thread's tip one tangent-segment of that length out from each point. The copper curve is a record of a tight string let go — and the gold base beneath it is the curve that string was wound on, its evolute.

A curve and its evolute are the same thing read two ways: wind a string on, and you have the curvature folded away; let the string off, and you have it back.
