# Tideline

**A daily mark for slow, tidal work.**

Tideline is a small page for the long projects that don't move in
straight lines — the book in its third draft, the thesis on its
ninth chapter, the renovation, the recovery, the language you've
been getting to know for two years. Each day you leave a mark
where the work reached. Some days the tide comes in. Some days it
goes back out. Over weeks, the line draws itself.

## The pitch in one breath

Slow work is tidal. It moves in and out, not forward and forward.
Tideline is one mark a day on the strand, so months from now you
can still see the shape of the year.

## Five kinds of mark

- **Reach** — the work moved out past yesterday's line. A new
  paragraph, a new measurement, a new mile.
- **Hold** — the line stayed where it was. You sat with the work
  and didn't lose ground.
- **Recede** — the line slipped. A revision pulled a chapter
  apart, a setback shortened the day, the tide went back out.
- **Pause** — chosen quiet. A rest day, a Sabbath, a week off
  with the work's blessing.
- **Storm** — life broke in. Not your choice. Not a failure.
  A mark all the same.

## What's in this folder

- `index.html` — the landing page with the in-browser strand.
- `styles.css` — a brackish palette: deep sea, wet sand, kelp,
  pale shell, driftwood; Fraunces for headings, Inter for body,
  JetBrains Mono for marginalia.
- `script.js` — a hundred-and-twenty seeded marks for a
  fictional six-month book draft; leave your own, slide the
  project length, reset.

## Running it

Open `index.html` in a browser. No build step.
