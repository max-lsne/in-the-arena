# Keystone

**The one stone that holds the arch up.**

An arch is not held up by the bottom stones. It is held up by the
keystone — the wedge at the top, set last, that locks the curve
into place. Pull it and the arch falls. Keystone is a small page
for that one stone in a week.

## The pitch in one breath

Most task lists want everything in them. The keystone is the
opposite. Most weeks have one task that, if it lands, makes the
week worthwhile — and a small set of supporting stones leaning
against it. Everything else belongs to a different week's arch.
Keystone is a page that asks for that one stone, and lets the
rest be what it is.

## The arch

- **The keystone** — the one task that holds the week. Set last.
  Named first.
- **The voussoirs** — the supporting stones. Each leans against
  the keystone, or against another voussoir.
- **The springers** — the stones at the foot. Small things that
  begin the arch and let the week start standing.

## The four states of a stone

- **Cut** — you have shaped it but not set it.
- **Set** — it is in the arch, holding.
- **Placed** — the mortar is dry. Done.
- **Removed** — you pulled it. Sometimes the arch is the wrong
  shape and a stone has to come out. Removed is honest.

## What's in this folder

- `index.html` — the landing page, with the arch widget in the
  browser.
- `styles.css` — a sandstone palette: limestone, sandstone,
  mortar, chalk, soot, ochre, indigo; Fraunces for headings,
  Inter for body, JetBrains Mono for marginalia.
- `script.js` — nine seeded stones for an imaginary week in the
  late spring of 2026. The keystone is a thirty-minute talk to
  the team about the year so far. The voussoirs lean against it.

## Running it

Open `index.html` in a browser. No build step.
