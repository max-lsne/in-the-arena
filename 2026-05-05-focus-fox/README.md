# FocusFox

> Your AI deep-work companion. It plans focus sessions around your real energy, shields you from distractions, and quietly nudges you back when you drift.

A static landing page concept built in a day.

## The idea

Most productivity tools assume your brain is a robot that runs on fixed 25-minute Pomodoros. FocusFox watches what actually happens in your day — when you ship things, when you stall, what you avoid — and builds a plan that respects that.

- **Energy-aware scheduling** — stacks hard work into your peak windows
- **Calendar-native** — Google / Outlook / Apple, real events with buffers
- **Adaptive sessions** — shrinks when you're tired, extends when you're flowing
- **Friction, not walls** — gentle 10-second pauses, not hard blocks
- **Weekly review, written for you** — one-page Friday summary

## Run it

Just open `index.html` in a browser. No build step.

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Files

- `index.html` — single-page marketing site
- `styles.css` — handcrafted dark theme with a warm accent
- `script.js` — smooth scroll, waitlist UX, reveal-on-scroll
