# Galley

**You do not read the run to find the typo. You read the proof, once, before
the press turns.**

A **galley** is the long tray that holds a column of set type, and the **galley
proof** is the single sheet a printer pulls from it before committing to the
press run — one inked copy, read cold, hunting the error the compositor's own eye
slid past while setting it. A typo caught on the proof costs one sheet and five
minutes with a pencil. The same typo caught after the run costs the whole
edition, pulped and reprinted. The proof is cheap on purpose so the run never has
to be.

Galley is a small page built around that one move: read the copy you can throw
away, closely, before you multiply the one you can't.

> The press does not know a good line from a turned one. It prints what is there,
> a thousand times, with equal care. The proof is the one chance to read before
> the multiplying starts.

## The run, and the proof

- **The run — the error, multiplied.** The full edition: paper, ink, press time,
  folding, binding. Every fault in the forme is faithfully copied onto every
  sheet. The run does not catch mistakes; it commits them, at scale.
- **The proof — the error, alone.** One sheet, pulled to be read and thrown
  away. It carries every fault the run would, but only once, where a pencil can
  still fix it. The whole skill is reading it as a stranger would, not as the
  hand that set it.

## What a proof catches

Not all reading is proofing. The eye that set the type already knows what the
line should say, and it will supply the missing letter for you every time.
Proofing is reading against that habit:

- **Glanced — looks about right.** You checked that it is type, not that it is
  correct. Every error survives a glance.
- **Skimmed — read for sense.** Sense is exactly what your eye repairs on the
  fly; the big errors go, the small ones stay.
- **Read cold — word by word, as a stranger.** The pass that pays. You read what
  is set, not what you meant to set. This catches the turned letter.
- **Sent unread — straight to the press.** Whatever is in the forme is now in
  every copy. You did not save the five minutes; you multiplied the cost.

The proof stands for any cheap, faithful copy you can read before you commit the
expensive one — the dry run, the preview, the read-through. It only works if you
read it cold. Read it as its author and you will proof your intentions, not your
text.

## The proof sheet

The sheet pulls a dozen lines of set type. Some carry a compositor's error — a
turned word, a dropped letter, a doubled sort — and at a glance they all look
like type, typo and all sitting right there in plain sight. **Read** a line to
catch what it hides; the correction is struck in the corrector's red. Or
**send** it unread and trust it to the press. The gauge keeps the tally: lines
read, errors caught on the throwaway sheet, and lines committed to the run sight
unseen. *Fresh pull* re-sets the forme, and the number of errors wanders a
little each time, so no two proofs read the same.
