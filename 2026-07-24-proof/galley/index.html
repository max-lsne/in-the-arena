A galley is the long tray of set type, and the galley proof is the single sheet a printer pulls from it before the press run — one inked copy, read cold, hunting the error the compositor's own eye slid past. A typo caught on the proof costs one sheet and five minutes. The same typo caught after the run costs the whole edition, reprinted. You read the one copy you can throw away so you never have to pulp the thousand you can't.

The proof is a rehearsal of the run, for one sheet

The run is the commitment. The proof is how you stop committing the error with it.

The type is set, the forme is locked, and it is all about to be multiplied — cleanly or not. The press does not know a good line from a turned one; it prints what is there, a thousand times, with equal care. The proof is the one chance to read before the multiplying starts.

The run — the error, multiplied

The full edition: paper, ink, press time, the folding and the binding. Every mistake in the forme is faithfully copied onto every sheet. The run does not catch errors; it commits them, at scale, and hands you the bill as a reprint.

The proof — the error, alone

One sheet, pulled on purpose to be read and thrown away. It carries every fault the run would, but only once, where a pencil can still fix it. The whole skill is reading it as a stranger would, not as the hand that set it.

A proof is read at more than one depth

Glanced, skimmed, read cold — only the last one catches the turned letter.

Not all reading is proofing. The eye that set the type already knows what the line is supposed to say, and it will supply the missing letter for you every time. Proofing is reading against that habit. From the laziest pass to the one that earns its keep:

  1. Glanced — looks about right. The shape of the paragraph is fine, the block is grey and even. You have checked that it is type, not that it is correct. Every error survives a glance.
  2. Skimmed — read for sense. You followed the meaning and nothing snagged. But sense is exactly what your eye repairs on the fly; "form" for "from" reads clean at speed. The big errors go, the small ones stay.
  3. Read cold — word by word, as a stranger. The pass that pays. You read what is set, not what you meant to set — slowly, against the grain of your own memory of the copy. This is the reading that catches the turned letter.
  4. Sent unread — straight to the press. The forme goes to the run on trust. Whatever is in it is now in every copy. You did not save the five minutes; you moved the cost to the reprint and multiplied it.

The proof stands for any cheap, faithful copy you can read before you commit the expensive one — the dry run, the preview, the read-through. It only works if you read it cold, as a stranger to the copy. Read it as its author and you will proof your intentions, not your text.

The whole of the method

Pull one sheet. Read it cold. Send only what you have read.

  1. 1

    Pull the proof

    Take one sheet off the locked forme — the same type the run will use, inked the same way. Cheap enough to mark up and throw away, faithful enough that its faults are the run's faults.

  2. 2

    Read it cold

    Read what is set, not what you meant. Word by word, against your memory of the copy. The turned letter and the doubled word hide in exactly the places your eye wants to smooth over.

  3. 3

    Send only the read lines

    Correct what the proof caught, and release the forme to the run. Every line you send unread is a line you are trusting to the press — and the press keeps no proofs.

Who reads one

For anyone who can check the copy before it multiplies.

The writer

Do not publish to find the typo. Read the draft cold, aloud, as a stranger — the sentence you wrote is the one you cannot see. What you catch on the proof is a pencil mark; what a reader catches is an erratum.

The developer

Do not ship to find the bug. Read the diff line by line before it merges — the change you made is the one your eye slides past. Caught in review it is a comment; caught in production it is an incident.

The sender

Do not send the mail to a thousand to find the broken link. Send the proof to yourself first and read it cold. The address list is the press: it copies faithfully, and it keeps no proofs.

Galley — the single proof sheet pulled from set type and read before the press run, so that an error caught on one throwaway copy for five minutes never becomes an error printed onto the whole edition; a cheap, faithful copy read closely ahead of the expensive one you cannot recall.
