# Lodestar

**The principles you've earned, when you actually need them.**

Lodestar is a quiet companion for hard decisions. You spent years learning
these — in notebooks, in chat exports, in late conversations with mentors.
Lodestar gathers them in one place and pulls one up the moment the next hard
call lands.

## The pitch in one breath

You don't have a knowledge problem. You have a loading problem.
The principle you needed on Tuesday was somewhere. Lodestar makes it the
thing that surfaces first.

## The loop

- **Capture** — Add a principle the day you earn it. One sentence. The
  version that survives stress.
- **Anchor** — Each morning Lodestar surfaces one. You read it. That's the
  ritual.
- **Use** — Tag the next hard decision to the principle that should guide
  it. Even before the call is made.
- **Audit** — Quarterly, see which principles fire and which never do.
  Sharpen the live ones. Retire the dead.

## What's in this folder

- `index.html` — the landing page and the in-browser demo.
- `styles.css` — parchment / ink / brass palette; Fraunces, Inter,
  JetBrains Mono.
- `script.js` — seven sample principles, a "draw anchor" loop, a decision
  log, and `J` / `K` / `Space` keyboard shortcuts. Everything runs in
  the browser.

## Running it

Open `index.html` in a browser. No build step.
