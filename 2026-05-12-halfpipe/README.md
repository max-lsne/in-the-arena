# Halfpipe

**Don't build the wrong startup. Test it from the top of the ramp.**

Halfpipe sends your one-page pitch to 50 anonymous builders — founders,
ex-founders, people shipping right now. Forty-eight hours later you get back
one Would-Pay Score, three distilled sentences, and the courage to either
commit or kill it.

## The pitch in one breath

The biggest cost of a wrong idea isn't the build. It's the year. Halfpipe
short-circuits that year with a small, well-screened panel and a single
question: *would you pay for this?*

## What's in this folder

- `index.html` — the landing page.
- `styles.css` — concrete + ink + sun palette; Newsreader / IBM Plex Sans / JetBrains Mono.
- `script.js` — interactive practice ramp. Type a pitch, set a price, watch 50 dots flip yes/no, get a mocked score, three quotes, and a verdict.

## Running it

Open `index.html` in a browser. No build step.
