# Tempo

> Work with your rhythm, not against it.

**Tempo** is a circadian-aware AI scheduler that learns when you focus, when you crash, and when you connect — then rebuilds your calendar around it.

This folder contains a static landing page for the idea.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` — single-page landing site
- `styles.css` — design tokens, layout, components
- `script.js` — waitlist form handler, scroll reveal, smooth anchors
