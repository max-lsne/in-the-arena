# Tinderbox

**Catch sparks before they go cold.**

Tinderbox is a 5-second capture for the half-formed ideas that arrive at
the worst possible moments — at a red light, in the shower, two minutes
before a meeting — paired with a quiet Sunday-morning ritual that
decides which sparks were actually worth keeping.

## The pitch in one breath

Capture is the easy half. What's missing from every notes app is the
second half: a small weekly ritual that says *this one's still warm,
this one's ash, both are fine.* Tinderbox is built around the sift.

## Three flavors, four verdicts

- **Line** — a sentence you don't want to lose.
- **Image** — a visual hunch, an object, a scene.
- **Hunch** — a half-question, a possible turn, a structural worry.

After Sunday's sift each spark carries a verdict:

- **Spark** — fresh, no commitment.
- **Kindling** — survived one sift; gets one more week.
- **Ember** — graduated to real work; leaves the box.
- **Ash** — let go on purpose. The majority. By design.

## What's in this folder

- `index.html` — landing page with the interactive spark log.
- `styles.css` — a dark hearth palette (ember orange, kindling yellow,
  cool ash) with Fraunces for display, Manrope for body, JetBrains
  Mono for marginalia. Respects `prefers-reduced-motion`.
- `script.js` — fourteen seeded sparks from a working novelist's week
  14. Re-flavor, re-verdict, capture a new one, reset.

## Running it

Open `index.html` in a browser. No build step, no dependencies.
