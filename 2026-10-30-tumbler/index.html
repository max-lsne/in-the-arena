tumbler · noun · /ˈtʌmblə/ — a pin, lever, or disc in a lock that must be lifted to just the right height before the bolt will move; from tumble, to fall, for the piece that drops into place behind the key — and so, the little gate that must be made to fall exactly right, or stay fallen and hold

Tumbler

A lock keeps one secret, and it is a plane. Lift every pin to it and the lock is open; miss it by a hair and it holds.

Inside a pin-tumbler lock is a row of little stacked pins, spring-pushed down into a plug that wants to turn inside a fixed shell. Each stack is cut in two — a short key pin below, a driver pin above — and at rest the break between them sits below the line where plug meets shell, so every driver bridges that line and nails the plug still. The whole machine is that one line, the shear line: raise each stack until its break rises to meet it, and nothing crosses the gap, and the plug turns. The key does this to all the stacks at once — its cuts are a frozen cast of exactly how far each must rise. A pick cannot lift them all together, and need not, because no lock is cut perfectly true. That flaw is the whole of picking: it gives the pins an order, and the order can be climbed.

Where the hold is

A row of broken pins on a line

Picture one stack. A spring presses down from the top of the shell; under it a driver pin, under that a key pin, and under that the keyway where the key slides in. With no key, the spring shoves the whole stack down as far as it goes, and the break between the two pins sits below the shear line — which means the driver pin, the upper one, hangs down across the line, half in the shell and half in the plug. It is a dowel driven through the seam of two parts, and the plug cannot rotate past it. Multiply by five or six stacks and the plug is pinned in as many places.

The lock is not locked by the key's absence. It is locked by pins deliberately set to cross a line — and opened by lifting each one until it just clears it.

Lift a stack and the break climbs. Raise it exactly right and the break lands on the shear line: now the key pin fills the plug to the line and no further, the driver fills the shell down to the line and no further, and the seam is clean. Lift it too far and you have only swapped the problem — now the key pin pokes up across the line, and the plug is jammed from the other side. There is a single correct height for each stack, and the measure of a lock is that these heights are all different and all hidden. The set of them — how deep each cut must be — is the bitting, and a key is nothing but that bitting carved into a strip of brass, delivering every lift at once the instant it seats.

The one plane, read a few ways

The shear line, the key, and the flaw that picks it

Take n stacks, each needing its own lift Lᵢ to bring its break to the shear line; take the torque you put on the plug to turn it; and take the one thing the catalogue never prints — the tolerance, the few thousandths by which the real chambers fail to line up true. The whole lock is these read against each other:

  • Opening is one equation, solved for every pin. The plug turns exactly when every break is at the shear line at the same moment — Lᵢ met for all i. Not most; all. One stack short and the plug is as locked as if none had moved. The secret is a single plane, and the pins are just the many places it can be missed.
  • The key solves it by geometry, all at once. A correct key carries every Lᵢ cut into its edge, so seating it raises all the stacks to the line in one stroke — the solution delivered whole. This is why a key feels like nothing: it is not fighting the lock, it is satisfying it everywhere simultaneously.
  • A pick solves it one pin at a time — on the lock's own flaw. Put a light torque on the plug. Because the chambers are not perfectly true, the plug rotates a few thousandths until it binds on the single stack whose chamber sits furthest off-line. All the torque now rests on that one pin. Lift it to the shear line and the plug rotates into the gap it leaves, trapping that driver on a tiny ledge — a set — and the binding passes to the next pin. One at a time, in the order the tolerance dictates, until the last set frees the plug.
  • The flaw is the whole method. A lock machined perfectly true — zero tolerance — has no stack that binds before the others, so there is no first pin, no order, nothing for the pick to climb. It cannot be picked pin by pin at all. It opens only to its key, which needs no order, or to force, which needs no finesse. The precision that would make a lock pickable is exactly the precision it lacks.

So the same plane reads three ways. To the locksmith it is a tolerance to be held as tight as cost allows; to the key it is a set of heights to be matched at once; to the pick it is an order to be discovered and climbed, rung by rung, the lock handing up one pin at a time precisely because it was built a little wrong. Tighten the tolerance and the lock grows harder to pick and dearer to make and — past a point no lock reaches — impossible to pick and useless without its key.

A key never learns the order of the pins. It does not need to: it answers the whole question in one word. The pick learns the order because that is the only way it is allowed to ask.

Four states, from a lock at rest to a plug set free

Around the one line

  1. Locked. No key, no torque. Springs hold every break below the shear line; every driver crosses the seam. The plug will not stir — this is the lock doing its one job, n dowels through a joint.
  2. Binding. Torque on, mid-pick. Exactly one stack carries the load — the one the tolerance set furthest off-line. The others are slack and free to lift; only the binding pin resists, and it is the only one worth touching.
  3. Set. A bound pin lifted to the line: the plug rotates a hair into the gap, catching the driver on a ledge so it cannot fall back. The pin is parked above the shear line, the torque moves on, and the count climbs toward n.
  4. Open. Every break on the line at once — the last pin set, or the key seated. Nothing crosses the seam, and the plug swings. By geometry if you had the key; by order if you did not.

One line, three trades

Who reads the shear line, and how

The locksmith

holds the plane

Reads the shear line as a tolerance to keep: chambers drilled as near true as the price allows, so the lock resists the pick but still turns sweetly on its key. Every thousandth tighter is cost, and security — up to the point of diminishing return nobody pays past.

The key

answers all at once

Carries the bitting — each stack's lift Lᵢ cut into brass — and delivers the whole solution the instant it seats. It never meets a binding pin, never climbs an order: it satisfies the plane everywhere, so the plug was never truly fighting it.

The pick

climbs the order

Cannot lift all the stacks together, so it exploits the flaw instead: light torque, find the one pin that binds, set it, let the torque pass on. It reads the lock as an order handed up pin by pin — an order that exists only because the lock was built a little untrue.

The bench

Open it by key, or by feel

A pin-tumbler lock in cross-section: a plug that wants to turn inside a fixed shell, a row of spring-loaded stacks crossing the shear line between them. Set the number of pins and the tolerance the chambers are cut to. Press Insert key to raise every break to the line at once and watch the plug swing free. Press Pick it to put torque on the plug instead and let it set the pins one at a time, in the order the tolerance dictates — or Set next pin to take that order a rung at a time yourself. Drop the tolerance to zero and the pick stalls: with no pin binding first, there is no order to climb, and only the key will open it.

Insert key raises every break to the shear line at once — the solution delivered whole. Pick it puts torque on the plug and sets the pins in binding order; Set next pin takes that order one rung at a time. The shear line is the seam between plug and shell; a driver crossing it is what holds. The binding-order panel ranks the chambers by how far each drifts off the true line — the ladder a pick climbs, top to bottom. Fit spool drivers and each catches in a false set before it clears — the plug over-rotates, then counter-rotates as it lets go. Rekey cuts a fresh bitting.
